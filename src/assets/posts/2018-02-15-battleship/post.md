I made a multiplayer browser version of Battleship using JavaScript, Socket.io, and Express. Players placed their fleet and took turns attacking each other. A Python watchdog monitored the server and restarted it when necessary.

[https://github.com/Drabble/Battleship/tree/master](https://github.com/Drabble/Battleship/tree/master)
